What is a Large Language Model?

An LLM is a neural network trained on massive text data to predict the next token.

Key Idea: Given "The cat sat on the ___", the model assigns probabilities to every possible next word and picks the most likely one.

GPT-4 LLaMA Claude Gemini

The Transformer Architecture

The engine behind every modern LLM — introduced in "Attention Is All You Need" (2017)

What Are Parameters?

Parameters are the learnable numbers (weights & biases) inside the neural network that get adjusted during training.

Think of them as millions of tiny knobs. Training = finding the right setting for each knob so the model produces good outputs.

Every connection between neurons has a weight. Every layer has biases. Together, they form the model's "knowledge".

How Parameters Are Trained

The 3-step loop that teaches an LLM to understand language:

Gradient Descent — Finding the Minimum

The goal: find parameter values that minimize the loss.

Gradient = direction of steepest increase
We go in the opposite direction!

# Update rule:
w = w - learning_rate * gradient

# Example:
w = 0.5 - 0.01 * (-2.3)
w = 0.5 + 0.023 = 0.523

Training in Action — Loss Over Time

Epoch 1: Loss = 4.2 Epoch 10: Loss = 1.5 Epoch 50: Loss = 0.3

Learning Rate — The Most Important Hyperparameter

What Are Embeddings?

Embeddings convert text into dense numerical vectors that capture semantic meaning.

Key Insight: Similar concepts end up close together in vector space!
"king" - "man" + "woman" ≈ "queen"

# Example embedding (simplified)
"cat" → [0.2, 0.8, -0.1, 0.5, ...]
"dog" → [0.3, 0.7, -0.2, 0.4, ...]
"car" → [-0.5, 0.1, 0.9, -0.3, ...]

# cat & dog are close!
similarity(cat, dog) = 0.95
similarity(cat, car) = 0.12

RAG: Retrieval-Augmented Generation

RAG combines the power of LLMs with external knowledge retrieval to generate more accurate, up-to-date answers.

Problem: LLMs have a knowledge cutoff and can hallucinate.
Solution: Retrieve relevant documents first, then let the LLM answer using those docs as context.

Reduces hallucination Always up-to-date Domain-specific

The RAG Pipeline

LangChain Framework

LangChain + RAG in Code

from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import Chroma
from langchain.chains import RetrievalQA

# 1. Load & chunk documents
loader = PyPDFLoader("company_handbook.pdf")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

# 2. Create embeddings & store in Chroma
embeddings = OpenAIEmbeddings()
vectorstore = Chroma.from_documents(chunks, embeddings)

# 3. Build RAG chain
llm = ChatOpenAI(model="gpt-4", temperature=0)
qa_chain = RetrievalQA.from_chain_type(
  llm=llm,
  retriever=vectorstore.as_retriever(search_kwargs={"k": 3}),
  return_source_documents=True
)

# 4. Ask questions!
result = qa_chain.invoke("What is our vacation policy?")
print(result["result"])

Tokenization — How Text Becomes Numbers

Before an LLM sees text, it must be split into tokens using algorithms like BPE (Byte Pair Encoding).

Self-Attention — Step by Step with Numbers

Tracing attention for the sentence "The cat sat" with embedding dim = 4

Positional Encoding — Order Matters

Transformers have no built-in notion of order. Positional encodings inject position info.

Problem: "Dog bites man" vs "Man bites dog" — same tokens, different meaning!
Solution: Add a unique position signal to each token's embedding.

# Sinusoidal Encoding (original)
PE(pos, 2i)  = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

# Position 0, dimension 0:
PE(0,0) = sin(0) = 0.000
# Position 1, dimension 0:
PE(1,0) = sin(1) = 0.841
# Position 2, dimension 0:
PE(2,0) = sin(2) = 0.909

Modern models (GPT, LLaMA) use learned positional embeddings or RoPE (Rotary Position Encoding) instead.

Activation Functions — Adding Non-Linearity

Without activations, a neural network is just matrix multiplication — a linear function.

Loss Functions — Measuring Error

Cross-Entropy Loss (used in LLMs)

Measures how different the model's predicted probability distribution is from the true distribution.

# True next token: "cat" (index 5)
# Model predicts:
probs = [0.01, 0.02, 0.05, 0.02,
         0.1, 0.7, 0.03, 0.07]
#                    ↑ p("cat")=0.7

# Cross-Entropy Loss:
loss = -log(0.7) = 0.357

# If model was wrong (p("cat")=0.01):
loss = -log(0.01) = 4.605 # much higher!

Vector Indexing — How Search Stays Fast

Brute-force search over millions of vectors is too slow. Approximate Nearest Neighbor (ANN) algorithms make it practical.

HNSW (Hierarchical Navigable Small World)

Idea: Build a multi-layer graph. Top layers have few "highway" connections for fast navigation. Bottom layers have dense local connections for precision.

Search process:

1. Start at top layer → greedy walk toward query

2. Drop to next layer → refine search

3. Bottom layer → find exact nearest neighbors

O(log N) search time Used by Chroma, Pinecone
